# 固定测试素材

`manifest.json` 不复制图片，只引用工作区现有的测试素材，避免产生第二份
大文件。运行基线前必须确认这些路径仍然存在，并记录 SHA-256。

当前清单包含 16 张来自男女两组长裤素材，用于先验证目录、命名、尺寸和
增量缓存。完整基线还需要补充细节图、模特图和模特细节图；在补齐之前，
不能把第一阶段标记为全部通过。
