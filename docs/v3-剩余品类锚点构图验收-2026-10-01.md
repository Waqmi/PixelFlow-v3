# v3 剩余品类锚点构图验收记录

日期：2026-10-01

## 已实现

- `socks`、`hat`、`gloves`、`knee_pads`、`bag` 已加入锚点入口。
- 袜子：膝盖上方到鞋底；检测到抬脚时上沿切换为腰线；缺少膝/踝返回旧逻辑。
- 帽子：头顶/帽子框/举高手腕取最高点，到胸口；支持帽子标签映射和缺少脸部时的检测框守卫。
- 手套：检测框与腕点外延合并前臂；窗口超过上半身上限时回退上衣窗口并提示。
- 护膝：髋到膝守卫、膝上下各半段；抬腿检测返回旧逻辑。
- 包：直接复用上衣锚点规则。
- 新品类宽度不足继续出图；补边结构闸门失败时改为裁切并提示，不生成 `skipped` 计划。
- 检测服务新增按品类取框，检测模型缺失/失败时返回空框并继续姿态方案。
- 规则版本已同步为 `v3-composition-9`。
