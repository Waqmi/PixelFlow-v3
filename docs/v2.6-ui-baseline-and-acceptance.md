# v2.6 UI 复刻基线与验收标准

## 目标

v3 保留 Tauri + Vue + Worker 技术架构，但四个用户界面以 v2.6 生产版为唯一
前端基准，目标是达到 99% 的视觉与交互一致性。本文是后续 UI 修改的唯一验收依据。

## 基准来源

- 参考实现：工作区中的 v2.6 生产版 `PixelFlow-App-v2.0-backup-20260911-1705/main_image_tool.py`。
- 参考行为：v2.6 实际运行结果，不以开发者主观推测或截图重绘代替。
- 参考资源：v2.6 的 Logo、设置图标、下拉箭头、字体和颜色定义。
- 参考窗口：v2.6 `resize(1120, 820)`；v3 产品最小窗口固定为 `960 × 640`，该尺寸由紧凑样式断点适配。

基线截图必须由 v2.6 和 v3 在同一台机器、同一显示缩放、同一测试数据下分别生成，
禁止使用不同缩放比例的截图进行比较。

## 页面范围

| 页面 | 必须复刻的内容 |
|---|---|
| 主界面 | Logo、标题、副标题、设置入口；输入/输出目录卡片；输出尺寸；Logo/唯品图/素材理解；品类比例模板；文件大小；生成状态与按钮 |
| 素材确认页 | 素材网格、缩略图、文件名、分类下拉框、分类依据、跳过模特图、主体比例滑块、确认/取消、确认进度 |
| 设置页 | 品牌设置、输出选项、模特图增强、关于四个页签；Logo 预览/更换/恢复；模型目录、模型状态、缓存和界面偏好 |
| 结果报告页 | 成功/跳过/失败/审查异常统计；输出位置复制；快捷打开；失败清单；失败重试；完成/关闭 |

## 视觉验收

### 几何

- 在标准 `1120 × 820` 和产品最小窗口 `960 × 640` 下验收。
- 所有主要容器边界、控件顺序和可见性必须与 v2.6 一致。
- 容器位置和尺寸误差不超过 ±1 CSS px；文字基线误差不超过 ±2 CSS px。
- 输入/输出区域使用 v2.6 的动态布局：宽窗口双列，窄窗口按 v2.6 断点调整，不允许按钮掉到下一行或遮挡其他内容。
- 标准窗口下主界面不能出现额外滚动条；`960 × 640` 下使用紧凑断点完整显示主流程，不出现横向滚动。

### 外观

- 页面背景、面板背景、边框、圆角、阴影、选中态和禁用态与 v2.6 对齐。
- 使用 v2.6 的字体栈、字号、字重和中英文案；不能用浏览器默认下拉框、默认复选框替代。
- 下拉框、复选框、目录按钮、设置图标和结果按钮使用自定义样式或资源，避免 WebView 原生控件造成明显差异。
- 排除窗口标题栏、系统字体抗锯齿和系统文件选择器后，非文字区域截图相似度不得低于 99%。

### 状态

- 初始、分析中、待确认、生成中、已完成、已取消、失败七种状态均需有对应页面截图。
- 状态变化不能改变 v2.6 的布局层级或导致页面跳动。

## 交互验收

每个页面的核心交互必须 100% 通过：

1. 目录输入支持点击选择、拖入（如 v2.6 支持）和手动输入；输出目录不能与输入目录混淆。
2. 尺寸支持多选，选中态和 v2.6 一致。
3. 品类下拉菜单支持完整 v2.6 选项、键盘选择、点击外部关闭和当前值回显。
4. 素材确认支持修改分类、跳过模特素材、调整主体比例、取消后保留已确认状态。
5. 设置页签切换、保存、取消、恢复默认和模型检测行为与 v2.6 一致。
6. 结果报告支持复制路径、打开输出目录、查看失败清单和仅重试失败项。
7. 键盘可操作性、焦点顺序、Esc 关闭和减少动态效果行为与 v2.6 一致。

## 后端隔离验收

UI 验收不依赖 v2.6 后端实现。v3 前端只通过 Worker 协议使用以下能力：

- `classify_materials`
- `start_generation`
- `cancel_generation`
- `retry_failed`
- `probe_models`
- `clear_cache`

页面不得直接导入图像处理、分类或模型模块。更换后端实现不能改变页面布局和交互。

## 截图对比流程

1. 固定显示缩放、窗口尺寸、主题和测试素材。
2. 启动 v2.6，依次截取四个页面的全部状态。
3. 启动 v3，使用同一输入和操作顺序截取对应页面。
4. 对齐截图后进行像素差异比较，并单独记录文字抗锯齿差异。
5. 任何结构性差异、控件缺失、交互路径差异直接判定不通过；不能用平均相似度掩盖。

## 交付门槛

只有同时满足以下条件，才允许宣称“v2.6 UI 复刻完成”：

- 四个页面在两个窗口尺寸下的视觉验收全部通过；
- 核心交互矩阵 100% 通过；
- 非文字区域截图相似度 ≥ 99%；
- v3 Worker 回归测试通过，且页面未耦合 v2.6 后端；
- macOS arm64 打包后再次完成一次冒烟验收。

当前状态：主界面已完成 960 × 640 紧凑断点和基础交互验收；四个页面的逐像素对照仍需使用固定测试素材完成，
因此暂不宣称达到 99% 复刻门槛。
