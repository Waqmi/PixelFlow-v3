# v2.6 输出基线

这份记录用于证明 v3 beta 没有改变 v2.6 的输出行为。基线必须用当前
`PixelFlow-App-v2.0` 实际运行生成，不能用人工推测替代。

## 固定配置

```text
尺寸：1440x1440、1440x1920、1125x1500
Logo：含 Logo、无 Logo
唯品图：单独记录
品类：自动识别 + 长裤模板
模型：无模型回退、外部 Pose/Seg 模型（可用时）
```

## 必须记录的字段

| 字段 | 说明 |
|---|---|
| fixture_id | 对应 `fixtures/manifest.json` |
| source_sha256 | 输入素材哈希 |
| v2_commit | 生成基线时的 v2.6 提交或工作树标识 |
| options | 完整生成选项 |
| output_files | 相对输出路径列表 |
| output_sha256 | 输出文件哈希；若算法存在非确定元数据，记录尺寸/像素摘要 |
| classification | 最终确认的素材类型 |
| warnings | 审查或降级提示 |
| cache_hit | 是否复用缓存 |

## 生成规则

基线生成前先清理目标输出目录，避免历史文件造成“数量正确”的假象。
每次基线必须保存运行配置和失败清单；不要只保存截图。

## T3 当前内置 legacy 基线

T3 使用仓库内 worker/pixelflow_core/legacy_engine，不把历史 .app
结果当作当前 legacy 行为。固定 16 张输入由 fixtures/manifest.json 提供。

    python tools/run_renderer_baseline.py \
      baselines/v2.6/legacy-current-20260927 \
      --mode legacy \
      --report baselines/v2.6/legacy-current-20260927-report.json

同一批输入生成 v3 后，可直接比较两棵输出树并把结果写入 JSON：

    python tools/run_renderer_baseline.py \
      baselines/v2.6/v3-current-20260927 \
      --mode v3 \
      --compare-root baselines/v2.6/legacy-current-20260927 \
      --report baselines/v2.6/v3-current-20260927-report.json

报告按 RGBA 通道计算每个文件的最大通道差值 max_diff、平均绝对误差 mae、PSNR、
差异框 diff_bbox、四类输出统计、差异分类和 legacy_engine_sha256。
聚合哈希按相对路径和文件字节排序计算，排除 __pycache__、.pyc 和
.pyo，因此不会因本地 Python 缓存变化而改变。

### 首轮差异分类阈值

这些阈值用于筛选人工复核项，不替代路径、尺寸和模式校验：

| 分类 | 条件 |
|---|---|
| 版本差异 | 非图像证据文件内容不同，或需要结合基线来源/legacy_engine_sha256 判断 |
| 可接受实现差异 | 路径、尺寸、模式相同，且 max_diff ≤ 2、mae ≤ 0.25、PSNR ≥ 50 dB |
| 需修复 | 缺失/多余文件、尺寸或模式不一致，或超出上述像素容差 |

透明图的 alpha 边缘、Logo 和唯品边框即使落在容差内也要在
review/ 拼图中人工确认；报告中的 classification 只是首轮筛选结果。
