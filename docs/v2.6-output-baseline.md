# v2.6 输出基线

这份记录用于证明 v3 beta 没有改变 v2.6 的输出行为。基线必须用当前
`PixelFlow-App-v2.0` 实际运行生成，不能用人工推测替代。

## 固定配置

```text
尺寸：1440x1440、1440x1920、1125x1500
Logo：含 Logo、无 Logo
唯品图：单独记录
品类：自动识别 + 长裤模板
模型：无模型回退、外部 Pose/Seg 模型（可用时）
```

## 必须记录的字段

| 字段 | 说明 |
|---|---|
| fixture_id | 对应 `fixtures/manifest.json` |
| source_sha256 | 输入素材哈希 |
| v2_commit | 生成基线时的 v2.6 提交或工作树标识 |
| options | 完整生成选项 |
| output_files | 相对输出路径列表 |
| output_sha256 | 输出文件哈希；若算法存在非确定元数据，记录尺寸/像素摘要 |
| classification | 最终确认的素材类型 |
| warnings | 审查或降级提示 |
| cache_hit | 是否复用缓存 |

基线生成前先清理目标输出目录，避免历史文件造成“数量正确”的假象。
每次基线必须保存运行配置和失败清单；不要只保存截图。
