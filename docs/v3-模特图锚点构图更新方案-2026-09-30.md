## 1. 系统概述

v3版本引入了**双轨裁剪系统**：
- **锚点裁剪**（Anchor Composition）：用于 `shirt` 和 `shoes`
- **保护区域裁剪**（Protected Region）：用于其他品类（pants、shorts、hat、gloves、knee_pads、bag、socks）

两种方式都基于**Pose关键点检测**和**Segmentation轮廓**的双模型协同，但计算逻辑完全不同。

### 1.1 背景与问题

| 品类 | 用户期望 | 改动前实际 |
|---|---|---|
| 鞋 | 以鞋为主体，带小腿 | 露到膝盖甚至胯部；20 张中方图全部未放大 |
| 上衣 | 头顶 → 大腿（露出大腿） | 头顶 → 膝盖 |

## 2. 根因（已验证）

| 编号 | 根因 | 证据 |
|---|---|---|
| R1 | 旧逻辑是"保护区（至少包含什么）+ 多层边距 + 渲染器 80% 规则"，没有任何规则规定下边界停在哪个部位，只会框多不会框准 | 代码审阅 |
| R2 | 鞋保护区横向 = 人物框 ± 40% 框宽 → 触发"宽度 ≥ 85% → 裁剪比 0.95"，方图不放大 | 20/20 张鞋方图窗口 = 原图高 67% |
| R3 | 鞋风险（人物框贴边等）强制裁剪比 ≥ 0.82/0.88 | 8/20 张竖图放大到 82% |
| R4 | 边距以人物框高度为单位，随动作（举手、弯腰）变化 | 代码审阅 |

## 4. 最终规则（当前代码 v3-composition-4）

### 4.1 通用规则
- 只作用于 **鞋（`shoes`）、上衣（`shirt`）** 的模特图；其他品类、细节图保持旧逻辑。
- 构图结果为裁剪窗口 `crop_box`，宽高比等于输出尺寸；渲染器直接裁切+缩放，不再经过 80% 规则。
- 方图与竖图共用同一套规则，仅宽高比不同。
- 锚点贴原图边缘时，该侧不留边距（原图已无像素可用）。

### 4.2 上衣（Shirt）锚点裁剪

#### 锚点定义
- **顶部锚点**：头顶
  - 取值：`min(Pose检测框顶部, Seg轮廓顶部)`
  - 存疑判定：两者差异 > 10% 图像高度
  
- **底部锚点**：臀部 + 40% 大腿长度
  - 臀部：左右臀部关键点（索引11-12）的Y坐标
  - 大腿长度估算：
    - 如果膝盖可见：`膝盖Y - 臀部Y`
    - 如果膝盖不可见但肩膀可见：`(臀部Y - 肩膀Y) * 0.8`
  - 最终底部 = `臀部Y + 大腿长度 * 0.40`

#### 裁剪窗口计算

**垂直方向：**
```python
window_height = (bottom - top) / (1.0 - margin_top - margin_bottom)
window_top = top - margin_top * window_height
# margin_top = 0.04, margin_bottom = 0.0
```

**水平方向：**
1. 收集主体横向范围 `subject_x`：
   - Pose：头顶到臀部区间内的所有可见关键点
   - Seg：头顶到臀部区间内的**所有轮廓像素**（包含袖子）
2. 计算需要的宽度：
   ```python
   needed_width = (subject_right - subject_left) / (1.0 - 2 * ANCHOR_SIDE_MARGIN)
   ```
3. 窗口宽度：
   ```python
   window_width = window_height * aspect_ratio
   ```
4. 如果主体过宽：
   - 允许放大到 `1.3` 倍
   - 超出部分会被裁切，并标记"主体过宽，左右已裁切"

**居中方式：**
- 横向：以主体左右边界中心为中心
- 纵向：从顶部锚点向下

#### 特殊处理
- **Upper Body视角**：如果有臀部关键点，归一化臀部位置到图像80%高度
- **保护区域模式**：如果检测到保护区域，以保护区域中心为纵向中心，裁剪比例在0.34-0.72之间
- **Group模式（双人）**：要求两个人头部完整可见，使用两人保护区域的并集

### 4.3 鞋（Shoes）锚点裁剪

用户确定的优先级：**① 绝不切鞋 → ② 鞋占画面宽度有留白、不满屏 → ③ 能不露膝就不露**。

#### 前置条件
- **单人照片**（多人鞋模特图不处理，返回 `None`）
- **至少有脚踝关键点**（索引15或16，否则返回 `None`）

#### 锚点定义
- **核心锚点**：脚踝关键点（索引15-16）
- **底部锚点**：鞋底
  - 取值：`max(Pose检测框底部, Seg轮廓底部)`
  - 存疑判定：两者差异 > 10% 图像高度

#### 保护框计算
1. **脚长估算**：
   ```python
   shank_length = distance(knee, ankle)  # 小腿长度
   foot_length = max(shank_length * 0.7, (bottom - ankle) * 1.6, image_height * 0.04)
   ```

2. **鞋子保护框**：
   ```python
   left = min(ankles_x) - foot_length
   right = max(ankles_x) + foot_length
   top = min(ankles_y) - foot_length * 0.45
   bottom = 鞋底（已确定）
   ```

3. **使用Seg轮廓收紧横向边界**：
   - 只计算脚踝到鞋底之间的Seg轮廓
   - 更新 `left` 和 `right`

#### 裁剪窗口计算

**尺寸策略：鞋子永不裁切**

```python
def width_for(fill):
    return max(shoe_width / fill, (bottom - top) / 0.60 * aspect_ratio)

# 默认：鞋占画布58%宽度
window_width = width_for(0.58)

# 如果膝盖可见且靠近鞋底，可以放大到63%（但确保膝盖不入镜）
if knee_top is not None:
    knee_free_width = (bottom - knee_top) / (1 - 0.04) * aspect_ratio
    window_width = max(width_for(0.63), min(window_width, knee_free_width))

window_height = window_width / aspect_ratio
```

**定位方式：从底部向上构建**
```python
window_top = bottom + 0.04 * window_height - window_height
```

**居中方式：**
- 横向：以**脚的中心**为中心（不是躯干中心！）
- 纵向：底部对齐

#### 风险标记
以下情况会标记为需要复核：
```python
if 脚部关键点不足:
    shoe_risk_reasons.append("脚部关键点不足")
if 人物框贴边:
    shoe_risk_reasons.append("人物框贴边")
if 膝盖角度 < 55度:
    shoe_risk_reasons.append("腿部动作幅度大")
if 单脚可见 且 膝盖角度 < 85度:
    shoe_risk_reasons.append("单脚或脚部遮挡")
```

几何事实（实测）：18 张可判断素材中，要同时满足"整只鞋 + 不太大 + 不露膝"，方图仅 8 张、竖图仅 5 张可能；其余由拍摄构图决定（两只鞋并排的宽度大于不露膝窗口能容纳的宽度），因此按上述优先级露膝。

### 4.4 分割模型的使用
- 分割输出新增 `mask_rows`（每行轮廓左右范围，原图比例）；掩码限制在检测框内并去除 letterbox，修复"向上扩图"素材越界（−19%）问题。
- 确认页分类：鞋/上衣的模特图先跑 Pose 判断视角，确认是模特图后跑分割（结果缓存），再带分割重算构图（Pose 结果进程内缓存）。
- 耗时：鞋/上衣模特图首次约 +0.6 秒/张（分割）；结果缓存后不再计算。

### 4.5 确认页文件夹抽样（用户选方案 C）
- 规则全判为细节图的文件夹：均匀抽样最多 **5 张**（含首尾）跑 Pose。
- 任一样本为模特图 → 该文件夹其余图片**逐张**跑 Pose（鞋/上衣再跑分割），每张有自己的构图计划。
- 已知残余风险：5 张样本全是细节图时，夹在中间的模特图仍会被漏判（用户已接受）。

### 4.6 质量保障机制

#### 边界存疑检测
当 Pose 检测框和 Seg 轮廓在关键边界位置差异过大时，标记为存疑：

```python
ANCHOR_DISAGREEMENT = 0.10

# 上衣：头顶存疑
if abs(pose_top - seg_top) > image_height * 0.10:
    hints.append("头顶边界存疑")

# 鞋：鞋底存疑
if abs(pose_bottom - seg_bottom) > image_height * 0.10:
    hints.append("鞋底边界存疑")
```

#### 裁切提示
当主体被裁切超过一定比例时，添加复核提示：

```python
ANCHOR_CROP_HINT = 0.15

side_cut_ratio = (left_cut + right_cut) / subject_width
vertical_cut_ratio = (top_cut + bottom_cut) / subject_height

if side_cut_ratio > 0.15:
    hints.append("主体过宽，左右已裁切" if sides_cropped else "原图比例不足，可能裁切")

if vertical_cut_ratio > 0.15 and "原图比例不足，可能裁切" not in hints:
    hints.append("原图比例不足，可能裁切")
```

#### 复核提示汇总
| 提示 | 触发条件 |
|---|---|
| 主体过宽，左右已裁切 | 上衣超过 1.3 倍放大上限，且裁掉主体宽度 > 15%（`ANCHOR_CROP_HINT`） |
| 原图比例不足，可能裁切 | 原图容不下窗口，裁掉主体（左右或上下）> 15% |
| 鞋底边界存疑 / 头顶边界存疑 | 骨骼人物框与分割轮廓相差 > 原图高 10% |

注意：鞋类提示由既有鞋类封装按"任一尺寸有 → 所有尺寸都显示"合并（既有设计，未改）。

### 5.2 支持的品类及其保护区域

#### Shorts（短裤）

**覆盖范围：**腰部到膝盖（不需要脚踝）

#### Hat（帽子）
```python

horizontal_margin = max(body_height * 0.05, bbox_width * 0.10)
```

**覆盖范围：**头顶到下巴

#### Gloves（手套）
```python
# 关键点：肘部(7-8)、手腕(9-10)
top = min(hand_points_y) - body_height * 0.08
bottom = max(hand_points_y) + body_height * 0.08
horizontal_margin = max(body_height * 0.06, bbox_width * 0.10)
```
**覆盖范围：**前臂到手腕

#### Knee Pads（护膝）
```python
# 关键点：膝盖(13-14)
center_y = avg(knee_points_y)
half_height = body_height * 0.16
top = center_y - half_height
bottom = center_y + half_height
horizontal_margin = max(body_height * 0.08, bbox_width * 0.12)
```
**覆盖范围：**膝盖中心 ± 16% 身高

#### Bag（包包）
```python
# 关键点：肩膀(5-6)、肘部(7-8)、手腕(9-10)、臀部(11-12)
points = [5, 6, 7, 8, 9, 10, 11, 12]
top = min(points_y) - body_height * 0.05
bottom = max(points_y) + body_height * 0.08
horizontal_margin = max(body_height * 0.06, bbox_width * 0.10)
```
**覆盖范围：**躯干+手臂区域

## 6. Model View 分类逻辑

### 6.1 分类标准

基于 `body_visibility()` 函数的分析结果：

```python
def body_visibility(detections, image_size):
    visible_keypoints = [index for index in range(17) if confidence >= 0.28]
    
    head = bool(visible in range(0, 5))
    upper_points = visible in range(5, 11)
    lower_points = visible in range(11, 15)
    feet_points = visible in (15, 16)
    
    return {
        "head": head,
        "upper_body": bool(upper_points),
        "lower_body": bool(lower_points),
        "feet": bool(feet_points),
        "hands": bool(visible in (9, 10)),
        "arms": bool(visible in (7, 8)),
        "visible_keypoints": count,
        "person_box_width_ratio": bbox_width / image_width,
        "person_box_height_ratio": bbox_height / image_height,
    }
```

### 6.2 Model View 类型

1. **full_body**：全身照
   - 条件：`has_feet` 且 `has_head_or_upper_body`
   
2. **upper_body**：上半身/肖像
   - 条件：`has_head_or_upper_body` 且 **不** `has_feet`
   
3. **lower_body**：下半身
   - 条件：`has_feet` 且 **不** `has_head_or_upper_body`
   
4. **group**：双人/多人
   - 条件：`len(detections) >= 2` 且每个人都有足够的关键点
   
5. **detail**：细节图
   - 条件：关键点过少或检测框过小

## 9. v3 vs v2 的主要区别

| 方面 | v2 | v3 |
|------|----|----|
| **裁剪方法** | 保护框 + 堆叠边距（所有品类统一） | 双轨系统：锚点裁剪（shirt/shoes） + 保护区域（其他） |
| **上衣逻辑** | 保护框扩边 | 锚点裁剪：头顶到大腿根（40%大腿长度） |
| **鞋逻辑** | 保护框扩边 | 锚点裁剪：鞋占58%-63%画布，膝盖不入镜 |
| **居中方式** | 统一使用躯干中心 | 鞋以**脚的中心**，其他以躯干中心 |
| **袖子处理** | 可能被裁切 | **包含袖子**计入主体宽度（Seg轮廓） |
| **双模型协同** | Pose为主 | Pose + Seg 相互验证和收紧边界 |
| **质量保障** | 基本裁切检查 | 边界存疑、风险标记、细节图复核、多维度检查 |
| **构图一致性** | 方图和竖图可能构图差异大 | 鞋的单脚/双脚照片在方图和竖图保持一致居中 |
